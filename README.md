# DailyTalk · 英语口语练习工作台

一个纯前端（零依赖、零后端）的英语口语日常练习工作台：虚拟外教 **Emma** 带你进行生活场景对话，并对你的每句话进行 **评分 + 纠错**。

## 功能总览

| 模块 | 说明 |
| --- | --- |
| 🏠 工作台 | 今日练习时长、连续打卡、累计次数、平均分、每日目标环、最近记录 |
| 👩‍🏫 外教互动 | 与外教 Emma 实时对话：浏览器语音识别输入 + 英文 TTS 朗读，可调语速/难度/中文提示 |
| 🛠️ 场景练习 | 10 个日常生活场景（咖啡店、餐厅、自我介绍、闲聊、问路、酒店、购物、看医生、机场、超市），每个场景含分步引导、示范回答、跟读金句 |
| 🎓 面试特训 | 针对国际学校本科招生行政岗的双语模拟面试：8 大考察维度 24 道高频题（中英双语题干与参考话术）、6 个岗位情景模拟（来访接待 / 热线答疑 / 招生宣传 / 平台维护 / 抗压出差 / 团队保密）、全真模拟面试（连答 6 题出总评）、35 条术语 + 16 条万能句式；支持英文作答（语法 + 内容覆盖 + 流利度 + 发音）与中文作答（要点覆盖 + 结构 + 流畅）双模式，得分点同义表达识别，避免「换个说法就不算分」 |
| 📊 学习报告 | 评分趋势折线图、四维能力雷达图、错误类型排行、个人错误本 |
| ✏️ 智能纠错 | 规则引擎实时检测 9 大类问题：冠词、单复数、主谓一致、时态、介词、搭配、中式英语、语序、拼写，每条附中文讲解 |
| ⭐ 口语评分 | 语法 / 词汇 / 流利度 / 发音 四维评分（发音基于语音识别置信度，打字输入自动降级为三维评分） |

## 运行方式

- 直接双击打开 `index.html`，或
- 本地起服务：`python -m http.server 8080` 后访问 `http://localhost:8080`
- 支持路由直达：`index.html#tutor`（外教对话）、`#scenarios`（场景）、`#interview`（面试特训）、`#report`（报告）

## 语音要求

- **语音识别**：需要 Chrome / Edge 浏览器 + 麦克风权限 + 网络（浏览器在线识别服务）；需在 `http://localhost` 或 `https` 环境打开。
- 无法使用语音时，打字输入同样可获得语法 / 词汇 / 流利度评分，只是没有发音分。
- **外教朗读**：使用浏览器内置 TTS（speechSynthesis），可选语速。

## 技术说明

- 纯 HTML / CSS / 原生 JavaScript，无任何外部依赖与网络请求（语音识别由浏览器自带能力完成）。
- 数据全部保存在浏览器 `localStorage`，不上传、保护隐私。
- 目录结构：
  - `index.html` 页面结构
  - `css/style.css` 全部样式（浅色主题、响应式）
  - `js/correct.js` 纠错规则引擎（可独立复用，暴露 `DailyTalkCorrect.analyze(text)`）
  - `js/data.js` 场景库 + 自由对话应答引擎
  - `js/interview-data.js` 面试特训数据（岗位题库 / 情景 / 术语 / 句式，全双语）
  - `js/interview.js` 面试特训模块（独立引擎：单题精练 / 情景模拟 / 全真模拟 / 术语速查）
  - `js/words-data.js` 单词大炮词库（3 本词书 300+ 词）
  - `js/words.js` 单词大炮游戏引擎（下落 / 击落 / 堆叠 / 计分 / 错词本）
  - `js/app.js` 应用主逻辑（视图、对话流程、语音、评分、图表）

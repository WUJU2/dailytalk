    欢迎来到 DailyTalk！

    这里有一位耐心的美国外教 Emma，和你进行日常生活英语对话，并在你说完后：

    • 🎤 语音识别：推荐使用 Chrome 或 Edge 浏览器，并允许麦克风权限；
    • ⭐ 口语评分：从 语法 / 词汇 / 流利度 / 发音 四维评分；
    • ✏️ 逐句纠错：说错的地方马上指出并给出正确说法和中文讲解；
    • 📈 学习报告：记录你的进步曲线与高频错误本。
    ℹ️

    使用说明

    • 外教互动：选择场景后进入对话；Emma 会说话，轮到你时点 🎤 说英文，或打字发送。
    • 说错了？：你的每条消息下会即时显示纠错卡片（原句 → 改法 → 中文讲解）。
    • 卡住了？：输入框上方会出现「示范回答」，点一下可参考，再开口模仿。
    • 场景练习：左侧「跟读金句」可逐句跟读；评分基于识别置信度，仅供参考。
    • 结束与评分：点击「结束并评分」查看四维雷达图与完整纠错清单。
    • 隐私：全部数据仅保存在你本机的浏览器中，不会上传。
    • 语音要求：语音识别需要网络环境（Chrome/Edge）；若无法使用语音，打字同样可以获得语法/词汇评分。
